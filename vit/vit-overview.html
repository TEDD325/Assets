Vision Transformer (ViT)

이미지를 패치 토큰의 시퀀스로 바꿔 Transformer encoder에 넣는 구조

ViT의 핵심은 이미지를 문장처럼 다룬다는 발상입니다. 아래 그림에서 이미지 패치에 마우스를 올리면, 그 패치가 시퀀스의 어느 토큰이 되는지 따라갈 수 있습니다.

ViT 처리 흐름도

각 토큰에 위치 정보가 더해져 공간 배열이 유지됩니다.

패치 = 토큰

16×16 패치를 펼쳐 선형 투영하면 D차원 벡터가 됩니다. 이 시점에서 이미지는 CNN처럼 격자가 아니라 그냥 벡터들의 집합이 됩니다. 토큰 개수는 N = HW / P²입니다.

기호 정리

P는 패치 한 변의 길이(픽셀)입니다. 16×16 패치라면 P = 16입니다.

기호의미예 (ViT-Base/16, 224×224 입력)
H, W입력 이미지의 높이·너비 (픽셀)224, 224
P패치 한 변의 길이16
C입력 채널 수3 (RGB)
N = HW / P²패치(=토큰) 개수224×224 / 256 = 196
P² · C패치를 펼친 벡터의 차원16×16×3 = 768
D선형 투영 후의 임베딩 차원768

전제 조건이 두 가지 붙습니다.

  • 패치가 정사각형이어야 P²으로 쓸 수 있습니다. 직사각형이면 N = (H/P_h)(W/P_w)가 됩니다.
  • H와 W가 P로 나누어떨어져야 합니다. 안 나눠떨어지면 리사이즈하거나 패딩합니다.

ViT-Base/16에서는 P²·C = 768이고 D도 768이라 두 숫자가 우연히 같습니다. 원래 별개의 값이니 헷갈리지 않는 게 좋습니다. ViT-Large/16은 D = 1024라 투영 전후 차원이 달라집니다.

위치 임베딩이 필요한 이유

self-attention은 집합 연산이라 입력 순서에 대해 순열 불변(permutation invariant)합니다. 즉 패치를 섞어도 출력이 그대로입니다. 그래서 학습 가능한 1D 위치 임베딩을 각 토큰에 더해 몇 번째 자리인지를 주입합니다. 논문에서 2D 위치 임베딩도 실험했지만 성능 차이는 크지 않았습니다.

class token이 하는 일

BERT의 [CLS]에서 가져온 장치입니다. 어떤 패치에도 대응하지 않는 학습 가능한 벡터를 맨 앞에 붙여두면, 인코더를 거치며 self-attention을 통해 모든 패치 정보를 끌어모읍니다. 마지막 층의 class token 출력만 MLP head에 넣어 분류하고, 나머지 패치 출력은 분류에 쓰지 않습니다. 대안으로 모든 패치 출력의 평균 풀링을 쓰기도 하며, 학습률만 맞추면 성능은 비슷합니다.
