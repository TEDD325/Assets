척도 vs 데이터 유형
헷갈리는 이유와 차이점

척도(Scale)는 "이 데이터로 어떤 연산을 할 수 있나?"를 판단하는 기준이고,
데이터 유형(Data Type)은 "이 데이터가 어떻게 생겼나?"를 설명하는 분류입니다.
두 개념은 서로 다른 렌즈로 같은 데이터를 바라보는 것입니다.

측정 이론
척도 (Scale)
데이터 값 사이에 어떤 수학적 관계가 성립하는지를 나타냅니다.
"이 데이터로 평균을 내도 되나? 비율을 말해도 되나?" 같은 분석 가능성을 판단할 때 씁니다.

관계 이해하기

두 개념은 어떻게 연결되나?

하나의 데이터에 두 개념이 동시에 적용됩니다. 예를 들어 "만족도 점수"는 순서형 데이터이면서 서열척도입니다.

데이터 유형 (어떻게 생겼나)
🔢 이산형
📈 연속형
🏷️ 명목형
🥇 순서형
척도 (어떤 분석이 가능한가)
1️⃣ 명목척도
2️⃣ 서열척도
3️⃣ 등간척도
4️⃣ 비율척도

연결 관계 읽는 법

명목형 → 명목척도 (1:1 대응)
순서형 → 서열척도 (1:1 대응)
연속형 → 등간 또는 비율척도 (0의 의미에 따라)
이산형 → 비율척도 (보통 0 = 없음)

실제 데이터 데이터 유형 척도 평균 OK? "2배" OK? 핵심 이유
혈액형 (A·B·O·AB) 명목형 명목척도 ❌ ❌ 순서도, 간격도 없음
만족도 (1~5점) 순서형 서열척도 ⚠️ 주의 ❌ 순서는 있으나 간격 불균일
섭씨 온도 (°C) 연속형 등간척도 ✅ ❌ 0°C는 "없음"이 아님
매출액 (원) 연속형 비율척도 ✅ ✅ 0원 = 진짜 없음
주문 건수 (개) 이산형 비율척도 ✅ ✅ 정수, 0건 = 없음
회원 등급 (브론즈~VIP) 순서형 서열척도 ⚠️ 주의 ❌ 순서는 있으나 간격 불균일
결제 수단 (카드·현금) 명목형 명목척도 ❌ ❌ 순서도, 간격도 없음
키 (cm) 연속형 비율척도 ✅ ✅ 0cm = 진짜 없음, 소수 가능
💡 척도를 판별할 때
"이 데이터로 어디까지 계산할 수 있나?"
순서 있나? → 간격 균일한가? → 0이 진짜 없음인가?
Yes가 하나씩 늘어날수록 명목→서열→등간→비율
💡 데이터 유형을 판별할 때
"이 데이터 값이 어떻게 생겼나?"
숫자인가 범주인가? → 숫자면 소수 가능한가? → 범주면 순서 있는가?
이산·연속·명목·순서형 중 하나로 분류
🔗 두 개념의 관계
두 개념은 같은 데이터를 다른 각도에서 본 것입니다
데이터 유형은 "값이 어떻게 생겼나"(형태·구조)  |  척도는 "어떤 분석이 가능한가"(분석 가능성)
명목형↔명목척도, 순서형↔서열척도는 거의 1:1 대응 / 이산·연속형은 0의 의미에 따라 등간 또는 비율척도로 나뉩니다.
