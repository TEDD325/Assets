반정형 데이터 (semi-structured data)

웹사이트 방문 로그란?

누군가 웹사이트에 방문할 때마다 서버가 자동으로 기록하는 데이터입니다. 엑셀처럼 완전히 정형화되어 있지는 않지만, 일정한 패턴이 있어 반정형(semi-structured)이라고 부릅니다.

💡 실제 서버에 저장되는 형태입니다. 사람이 읽기 어렵죠? 이 텍스트를 프로그램이 파싱(분해)해서 의미 있는 데이터로 만듭니다.

ℹ️ 상태 코드(Status Code)는 서버가 요청을 어떻게 처리했는지 알려주는 3자리 숫자입니다. 앞자리 숫자가 가장 중요합니다.
2xx
성공 200 OK 201 Created

서버가 요청을 정상적으로 처리했습니다. 200이 가장 흔하며 "페이지를 잘 불러왔어요"라는 의미입니다. 201은 새 데이터(회원가입, 글 작성 등)가 성공적으로 생성됐을 때 사용합니다.

3xx
리디렉션 301 Moved 302 Found

요청한 페이지가 다른 주소로 이동했습니다. 브라우저가 자동으로 새 주소로 이동합니다. 301은 영구 이동(도메인 변경), 302는 임시 이동에 사용합니다.

4xx
클라이언트 오류 404 Not Found 403 Forbidden

사용자 측 문제입니다. 없는 페이지를 요청(404)하거나 권한 없는 페이지에 접근(403)한 경우입니다. 서버는 정상 동작 중이지만 요청 자체가 잘못된 것입니다.

5xx
서버 오류 500 Server Error 503 Unavailable

서버 측 문제입니다. 서버 코드에 버그가 있거나 과부하가 걸린 경우로, 개발자가 즉시 조치해야 합니다. 로그에서 5xx 비율이 갑자기 오르면 장애 신호입니다.

📊 분석 팁: 로그에서 5xx 비율이 갑자기 오르면 서버 장애 신호, 404가 특정 URL에 집중되면 깨진 링크를 의심합니다. 상태 코드별 비율을 시계열 그래프로 그리는 것이 기본 모니터링입니다.

왜 반정형 데이터인가?

✓ 패턴이 있음
필드 순서와 구분자가 일정해 프로그램이 파싱 가능
✗ 스키마 없음
DB처럼 고정된 컬럼 정의가 없고, 로그 형식이 버전마다 다를 수 있음
⋯ 선택 필드 혼재
어떤 행에는 User-Agent가 있고, 없는 행도 존재할 수 있음
